使用教程・FAQ

为了第一次使用 UTAU 的人也能看懂，这里整理了导入步骤和容易卡住的地方。

SET UP

导入步骤

UTAU 本体需要另行安装，请从官方网站下载。

  1. 在 BowlRoll 下载

    从下载页前往配布页，选择 VCV 或连单版本下载压缩包。

  2. 输入下载密码

    在配布页点下载时输入下载密码 0719。拿到压缩包后请完整解压，不要在压缩软件里直接双击打开。

  3. 放进对应引擎的文件夹

    UTAU 放进安装目录下的 voice；OpenUtau 放进 Singers 目录，或在偏好设置里添加歌手路径。

  4. 重启并选择音源

    打开 UTAU 或 OpenUtau，在音源列表选择「秋音棠」。两个版本都装了的话，会分别显示。

ENGINES

两种引擎的放置位置

同一份声库文件夹，UTAU 与 OpenUtau 都能直接读取，不需要转换格式。

UTAU

UTAU（Windows）

把声库文件夹放进 UTAU 安装目录下的 voice 文件夹，重启后在音源列表选择。

  • 放置位置UTAU 安装目录 / voice
  • 生效方式重启 UTAU
OpenUtau

OpenUtau（Win / macOS / Linux）

放进 OpenUtau 的 Singers 文件夹，或在偏好设置里添加歌手搜索路径。

  • 放置位置OpenUtau / Singers
  • 读取内容oto.ini（无需转换）

FAQ

常见问题

OpenUtau 可以用吗？

可以。两款声库都是 UTAU / OpenUtau 通用的：把声库文件夹放进 OpenUtau 的 Singers 目录，或在偏好设置里添加歌手路径即可，OpenUtau 会直接读取包内的 oto.ini。

两个版本可以同时安装吗？

可以。VCV 与连单是独立文件夹，放在同一个目录下即可，音源列表里会分别显示，互不影响。

VCV 和连单有什么区别？

VCV 是连续音声库，歌词按「- あ」这样的连续音格式写；连单由单独音（CV）和 VCCV 的 VC 部组成，主唱用单独音「あ」，音节之间用 VC 补衔接。连单比纯单独音连贯，也比 VCV 好上手。拿不准的话可以两个都下载，对比着用。

下载密码是什么？

两个版本的 BowlRoll 下载密码都是 0719，在配布页点下载时输入；它不是压缩包的解压密码，解压 zip 本身不需要密码。复制时注意不要带上多余的空格。

配布页打不开

配布页在外部站点 BowlRoll，可能会因为网络或维护暂时无法访问。请稍后重试；如果长时间无法打开，可以通过页脚的配布页链接确认最新状态。

音源列表里没有「秋音棠」

请确认声库文件夹是否直接放在 UTAU 的 voice 文件夹里。如果出现双层文件夹，请把里层移出来。重启仍无效时，可以尝试把文件夹名改成半角英文。

放了音符却没有声音

请确认音源是否选中、音符是否在音域内。把重采样器改成「model4」或「w4u」可能会改善。仍然没有声音时，请检查 UTAU 的输出设备设置。

声音破音・有噪音

调低参数 g 的值（例如 g-8）可以降低音量、减少破音。也请检查原音设定里的「先行发声」与「重叠」是否被设成了极端值。

想在 Mac 上使用

UTAU 是 Windows 软件。Mac 上可以使用 UTAU-Synth 等兼容软件，或通过 Wine 等环境运行。无法保证正常运行，请谅解。

GLOSSARY

术语表

CV（单独音）
逐个录制「あ」「い」等单音的方式。容易上手，但衔接处比较明显。
VCV（连续音）
把前一个音和后一个音连起来录制（如「a あ」），可以唱得更顺滑。
连单
由单独音（CV）与 VCCV 的 VC 部组成的声库。主唱用单独音，音节之间用 VC 补衔接。
oto.ini（原音设定）
调整每个音的长短与衔接的配置文件。没有它就无法正确演唱。
frq（频率表）
记录声音音高变化的文件，有助于稳定音准。
重采样器
转换音高的引擎，会改变音质与手感。
